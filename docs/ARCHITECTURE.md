# Архитектура

Файл создан harness-kit и принадлежит проекту: опишите здесь слои и границы модулей. Агенты читают его перед изменениями, структурный тест `scripts/verify` проверяет границы по блоку слоёв ниже.

## Слои

Слой — набор путей и список слоёв, которые он может импортировать. Импорт в слой, которого нет в `may_import`, — нарушение структурного теста. Файлы вне слоёв не проверяются; пустой список — проверка проходит с пояснением. После правки блока запустите `harness-kit sync`: он перенесёт слои в настройки проверки.

Пример:

```yaml
layers:
  - name: domain
    paths: ["src/domain/**"]
    may_import: []
  - name: app
    paths: ["src/app/**"]
    may_import: [domain]
```

Слои проекта:

```yaml harness-layers
layers: []
```
