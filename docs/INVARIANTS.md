# Инварианты

Файл создан harness-kit и принадлежит проекту. Здесь — то, что должно быть верно всегда, независимо от изменения: целостность данных, права доступа, обратная совместимость. Ревьюер и агент сверяют с этим списком каждое изменение; нарушение инварианта — провал ревью ([`REVIEW.md`](../REVIEW.md)).

Формат: одно утверждение на пункт и где оно обеспечивается.

- Пример: секреты не попадают в журналы и ответы API — проверяется в `src/log/redact.ts` и тестом `src/log/redact.test.ts`.
