# Объяснение harness в проекте

Ты отвечаешь на вопрос человека о harness-kit в этом проекте. Вопрос — `$ARGUMENTS`; если он пуст, дай обзор. Отвечай по фактам проекта: их собирает команда рантайма harness, а подробности — файлы, которые она называет источниками. Файлы проекта не меняй и команд, которые что-то меняют, не запускай: это объяснение, а не действие.

Команду рантайма запускай отдельным вызовом из корня проекта, ровно в том виде, как она написана ниже: без `cd`, `;`, `&&`, `|`, `$(...)` и переменных оболочки. Так её пропускает разрешение этого скилла.

## 1. Тема

Выбери тему по вопросу:

| Вопрос о том | Команда |
| --- | --- |
| что сделает команда `harness-kit <имя>` | `node harness/core/runtime.mjs explain --json command <имя>` |
| что проверяют CI и ворота, почему PR нельзя слить, как обойти | `node harness/core/runtime.mjs explain --json gates` |
| одна проверка `verify` (lint, types, tests…) | `node harness/core/runtime.mjs explain --json check <имя>` |
| почему правило ревью такое, какие правила есть | `node harness/core/runtime.mjs explain --json rule <слова из правила>` |
| как устроен файл, папка или модуль проекта | `node harness/core/runtime.mjs explain --json path <путь от корня>` |
| профиль, его умолчания, собственный профиль команды | `node harness/core/runtime.mjs explain --json profile <имя>` (без имени — профиль проекта) |
| что-то другое или всё сразу | `node harness/core/runtime.mjs explain --json` |

Если вопрос задевает несколько тем, запусти несколько команд — каждую отдельным вызовом. Имя проверки или команды, которого нет, команда назовёт с перечнем существующих: выбери из перечня и запусти снова.

## 2. Факты

Команда отвечает JSON `{ "topic", "subject", "lines", "data", "sources" }`: `lines` — готовые строки объяснения, `data` — те же факты полями, `sources` — файлы проекта, из которых они взяты. Чтобы ответить на «почему», открой источники (`Read`, `Grep`): текст правила в файле правил ревью, слои в документе архитектуры, причины уровня риска в документе рисков, решения в папке ADR проекта, если она есть.

Код выхода 2 и `unknown command 'explain'` — рантайм проекта старее скилла: скажи, что поможет `harness-kit upgrade`, и ответь по файлам проекта сам (конфиг `harness.config.yaml`, правила ревью, документы риска и архитектуры). Сообщение, что harness не установлен, — так и скажи. Другая ошибка — покажи её.

## 3. Ответ

Ответь по-русски, коротко и по делу: сначала прямой ответ на вопрос, затем почему так, со ссылками на файлы (`путь:строка`, где это уместно). Не выдумывай: чего нет ни в фактах, ни в источниках, того не утверждай — скажи, какой файл или команда это покажет. Для точного плана команды, которая меняет проект, предложи человеку запустить её с `--dry-run`: он печатает план и ничего не меняет.
